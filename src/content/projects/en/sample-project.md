## Context

[draft] In 2026, I am replacing my old Vue 3 portfolio with a static Astro site.

## The problem

[draft] Adding a project meant editing 3 Vue components.

## What I did

[draft] I split the site into 12 features, each with its own specification and plan.

## Stack and why

[draft] Astro outputs HTML pages with no client JavaScript, and TypeScript validates every entry at build time.

## Outcome

[draft] Adding a project takes 1 Markdown file, and the home page weighs under 200 kB.

## What I learned

[draft] A specification written before the code saves me from redoing a page twice.
