# Contract: i18n module and bilingual pages

## `src/i18n/ui.ts`

```ts
export const locales: readonly ['fr', 'en'];
export type Locale = 'fr' | 'en';
export const defaultLocale: 'fr';
export const fr: { … };              // reference dictionary
export type UiKey = keyof typeof fr;
export const en: Record<UiKey, string>;
```

## `src/i18n/utils.ts`

| Function                       | Returns                  | Behaviour                                                                                                                    |
| ------------------------------ | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `getLocale(value)`             | `Locale`                 | `'en'` if `value === 'en'`, else `'fr'`. Called with `Astro.currentLocale`.                                                  |
| `useTranslations(locale)`      | `(key: UiKey) => string` | Looks up the locale's dictionary. Unknown key = type error.                                                                  |
| `localizePath(path, locale)`   | `` `/${string}` ``       | Removes a leading `/en` segment, then adds `/en` for `en`. Keeps the trailing slash.                                         |
| `switchPath(pathname, locale)` | `` `/${string}` ``       | Target of the switcher from a page in `locale`: same path in the other locale if that route exists, else that locale's home. |

`localizePath` cases (must hold, checked in quickstart):

| Input            | `fr`          | `en`             |
| ---------------- | ------------- | ---------------- |
| `/`              | `/`           | `/en/`           |
| `/en` · `/en/`   | `/`           | `/en/`           |
| `/projects/`     | `/projects/`  | `/en/projects/`  |
| `/en/projects/x` | `/projects/x` | `/en/projects/x` |
| `/about`         | `/about`      | `/en/about`      |
| `/english`       | `/english`    | `/en/english`    |

The prefix is a whole segment: `/english` is not an English path.

## Page pattern

```astro
---
// src/pages/en/index.astro — shell only, same in src/pages/index.astro
import HomeView from '../../views/HomeView.astro';
---

<HomeView />
```

- A view (`src/views/<Name>View.astro`) holds the markup, styles and per-locale prose of a
  page, renders `BaseLayout`, and reads its locale from `Astro.currentLocale` (R3).
- A shell contains nothing but the view: no markup, no prop, no style.
- A French-only page (blog, from F10) has no view and no `en/` shell.

## Layout and components

- `BaseLayout`: `<html lang={locale}>`; skip link text = `t('skipLink')`. Props unchanged
  (`title`, `description`).
- `Header`: name link → `localizePath('/', locale)`; renders `Navigation` then `LangSwitcher`.
- `Navigation`: `aria-label={t('nav.label')}`; each entry `t(key)`, href
  `frenchOnly ? href : localizePath(href, locale)`; current-item rule from F02 applied to the
  localized href.
- `LangSwitcher` (new): one `<a>` (R6):
  `href={switchPath(pathname, locale)} hreflang={other} lang={other}
aria-label={`${t('langSwitch.short')}, ${t('langSwitch.label')}`}` with text `t('langSwitch.short')`. No `<script>`.
- `Footer`: labels from `footer.*`.
- No component contains a UI literal (constitution VI); proper nouns from `site.ts`
  (`site.name`) are data, not labels.
